# MindNest: Mini App онлайн-школы психологии

Telegram Mini App и PWA для онлайн-школы психологии. Внутри: лид-магнит (тест на тревожность, гид «5 техник» и промокод), тапалка в стиле Hamster с внутренней валютой «искры», магазин наград, каталог курсов и профиль.

Все данные (школа, курсы, авторы, отзывы, лицензия) выдуманы для демо. Меняются в двух файлах: `js/config.js` и `js/data.js`.

## Что внутри

| Экран | Что делает |
|---|---|
| Онбординг | 3 слайда, показывается один раз |
| Главная | Карточка лид-магнита, трекер настроения, направления, быстрые практики, задания за искры, курсы |
| **Тапалка** (центральная кнопка Ψ) | Тап по «ядру» даёт искры. Есть энергия с восстановлением, уровни, криты-«инсайты» ×5 с психологическими фактами, бусты (мультитап, запас энергии, 3 бесплатных восстановления в день) |
| Лид-магнит | Тест из 7 вопросов → форма (имя, контакт, согласие на ПД) → результат → гид «5 техник» + код −10% на 72 часа + 1000 искр |
| Магазин | Практики (открываются прямо в приложении), промокоды на скидки, мини-сессия с психологом, мерч. Покупка за искры выдаёт код, который активируется у менеджера |
| Курсы | Каталог с фильтрами, карточка курса: программа, формат, автор, отзывы, кнопка «Записаться» (пишет менеджеру и сразу подставляет промокоды) |
| Профиль | Статистика, график настроения, покупки, результат теста, рефералка, о школе |
| Дыхание 4-7-8 | Анимированная практика с вибрацией, засчитывается как ежедневное задание |

## Фулскрин

- **В Telegram**: `requestFullscreen()` (Bot API 8.0+) на iOS и Android, `disableVerticalSwipes()`, чтобы свайп при тапании не сворачивал приложение, отступы под чёлку и кнопки Telegram через `--tg-safe-area-*`.
- **В браузере на Android**: Fullscreen API по первому нажатию «Далее».
- **iPhone вне Telegram**: Safari не даёт веб-страницам уходить в фулскрин. Нужно «Поделиться → На экран „Домой“», после этого приложение открывается без панелей (`manifest display: fullscreen`).

## Запуск локально

Сборка не нужна, это чистые HTML/CSS/JS-модули. Но открыть `index.html` двойным кликом не получится: модули требуют сервер.

```bash
cd mindnest-app
python3 -m http.server 5173
```

Открыть http://localhost:5173 и в DevTools включить мобильный режим.

## Деплой на GitHub Pages

1. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
2. Через 1–2 минуты сайт доступен по адресу `https://<ник>.github.io/<репозиторий>/`.

## Подключение к Telegram-боту

1. @BotFather → `/newbot` → получить бота.
2. @BotFather → `/newapp` → выбрать бота, указать URL с GitHub Pages и короткое имя (например `app`). Получится ссылка `https://t.me/<бот>/app`.
3. Чтобы приложение открывалось кнопкой у поля ввода: @BotFather → `/mybots` → бот → Bot Settings → Menu Button → тот же URL.
4. Вставить ссылку `https://t.me/<бот>/app` в `CONFIG.links.miniApp`: она нужна для реферальных ссылок.

## Куда уходят заявки из лид-магнита

`CONFIG.leadsWebhook` в `js/config.js`. Приложение шлёт `POST` с JSON:

```json
{ "name": "Анна", "contact": "@anna", "score": 9, "result": "Волны на поверхности",
  "promo": "GIFT-7KQ2PX", "answers": [1,2,1,2,1,1,1], "at": 1760000000000,
  "source": "anxiety_test", "tg_user": { "id": 123, "username": "anna" },
  "init_data": "<подпись Telegram>", "ref": "ref_456" }
```

Самый быстрый вариант: Google Apps Script, который пишет заявку в таблицу.

```js
// script.google.com → Новый проект → вставить → Развернуть → Веб-приложение → доступ «Все»
function doPost(e) {
  const d = JSON.parse(e.postData.contents);
  SpreadsheetApp.openById('ID_ТАБЛИЦЫ').getSheetByName('Лиды')
    .appendRow([new Date(), d.name, d.contact, d.score, d.result, d.promo, d.tg_user && d.tg_user.username, d.ref]);
  return ContentService.createTextOutput('ok');
}
```

URL развёртывания вставить в `leadsWebhook`. Подойдут и n8n, и Make: там нужен Webhook-узел, после него отправка в CRM или в Telegram менеджеру.

## Что поменять под реального клиента

- `js/config.js`: название, ник менеджера, канал, ссылка на Mini App, политика ПД, webhook, экономика (энергия, награды, цены бустов).
- `js/data.js`: курсы, цены, авторы, отзывы, товары магазина, вопросы теста, тексты гида.
- Цвета: переменные в начале `css/styles.css`.

## Ограничения текущей версии

Это MVP без бэкенда, и об этом нужно знать заранее:

1. **Баланс хранится на устройстве** (localStorage + Telegram CloudStorage), поэтому продвинутый пользователь может его подделать. Пока награды выдаёт менеджер вручную по коду, это терпимо: менеджер видит код и может проверить. Скидками на автомате без сервера рисковать нельзя.
2. **Промокоды генерируются на клиенте.** Их не получится проверить автоматически при оплате, только вручную.
3. **Подписку на канал и приглашение друга** проверить без бота нельзя, задание засчитывается по клику.

### Что дальше (когда пойдёт трафик)

- Маленький бэкенд (Node.js + Postgres, или Supabase для скорости): баланс, покупки и промокоды хранятся на сервере.
- Проверка `initData` по HMAC с токеном бота на каждом запросе: так сервер знает, что это реальный пользователь Telegram.
- Тапы отправлять пачками раз в 3–5 секунд, сервер проверяет лимит (не больше энергии и не больше ~15 тапов в секунду).
- Бот проверяет подписку на канал через `getChatMember`, рефералы засчитываются по `start_param` только новым пользователям.
- Промокоды проверяются по базе при оплате (ЮKassa / Prodamus webhook).

## Структура

```
index.html            точка входа, подключает Telegram SDK
manifest.webmanifest  PWA, display: fullscreen
css/styles.css        вся вёрстка и тема
js/config.js          настройки школы и экономики  ← правится под клиента
js/data.js            контент                      ← правится под клиента
js/app.js             экраны, роутер, логика
js/store.js           состояние, сохранение, экономика
js/telegram.js        обёртка над Telegram WebApp API
js/art.js             SVG-иллюстрации
js/icons.js           иконки
```
